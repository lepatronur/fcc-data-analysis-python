# Data Analysis with Python - freeCodeCamp Projects

This repository contains my solutions to the five certification projects required for the **Data Analysis with Python** certification from [freeCodeCamp](https://www.freecodecamp.org/).

## 🛠️ Tech Stack
- **Language:** Python 3

## 📋 Project List

### 1. Mean-Variance-Standard Deviation Calculator
A function that uses NumPy to output the mean, variance, standard deviation, max, min, and sum of the rows, columns, and elements in a 3x3 matrix.
- **Status:** ✅ Completed
- **Tools:** NumPy

### 2. Demographic Data Analyzer
An analysis of a dataset of demographic data extracted from the 1994 Census database using Pandas.
- **Status:** ⏳ In Progress
- **Tools:** Pandas

### 3. Medical Data Visualizer
Exploring the relationship between cardiac disease, body measurements, blood markers, and lifestyle choices using charts.
- **Status:** 📅 Planned
- **Tools:** Pandas, Matplotlib, Seaborn

### 4. Page View Time Series Visualizer
Visualizing time series data using line charts, bar charts, and box plots to analyze patterns in page views.
- **Status:** 📅 Planned
- **Tools:** Pandas, Matplotlib, Seaborn

### 5. Sea Level Predictor
Analyzing a dataset of the global average sea level change since 1880 to predict the sea level change through the year 2050.
- **Status:** 📅 Planned
- **Tools:** Pandas, Matplotlib, SciPy
